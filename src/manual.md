# 简记操作手册

这份手册讲清楚简记怎么用。看完可以直接删掉，不影响任何功能。

## 一、界面分成三栏

从左到右：**笔记本** → **笔记列表** → **编辑器**。

- 第一栏管分类：全部笔记、未分类、你建的笔记本
- 第二栏是当前范围内的笔记，点一下就在右边打开
- 第三栏写内容，右上角有置顶和删除

最左边那一栏可以用 `⌘\` 收起来，把空间让给编辑器。

## 二、笔记本

笔记本就是一个「大模块」，把相关的笔记归到一起。比如「工作」「读书」「灵感」。

**新建**：点左下角「＋ 新建笔记本」，输入名字回车。

**移动笔记**：打开一篇笔记，点编辑器右上角那行里橙色的笔记本名，在下拉里选目标。

**重命名**：鼠标移到笔记本名字上，右边会出现 ✎，点它改名。整个文件夹会跟着改名，里面的笔记一起搬过去。

**删除**：点 ✎ 旁边的 ×，或者右键选「删除」。里面还有笔记也能删 —— 会先问你怎么处理：默认把这些笔记**移到「未分类」**（一篇都不会丢），也可以选「连笔记一起删掉」。

**右键笔记本**有四个操作：置顶 / 取消置顶、重命名、删除。置顶的笔记本排在列表最前面，前面会显示一颗 ★。

第一次打开时会自动建一个「记账本」，并且默认置顶。

## 三、笔记

点「＋ 新建笔记」新建，标题默认就是新建那一刻的时间（年月日时分秒，如 `20261021110636`），想改就直接改。

**右键笔记**同样有：置顶 / 取消置顶、重命名、删除。置顶的笔记固定排在列表最上面，标题后面有个小圆点。

- **置顶**：不用先打开，直接在列表里右键那篇就行
- **重命名**：改标题，文件名一起改
- **删除**：删的是磁盘上的文件，不进废纸篓，会先问一次

标题就是文件名：改完标题、点到别处（或按回车、切换笔记），文件会跟着改名，不用另外保存。

打开就能直接写，**看到什么样，存下来就是什么样** —— 没有「编辑」和「预览」的切换。标题、粗体、列表、待办、图片都在页面上直接长成最终的样子。

正文上方有一条小工具条，从左边开始是：

- **正文 / 标题**：切换普通段落和标题
- **B / I / S**：加粗、斜体、删除线
- **</>**：行内代码
- **• / ☑ / ❝**：圆点列表、待办清单、引用
- **图片**：选一张图插到光标处

也支持快捷输入，在行首敲就会自动变形：

- `# ` 加空格 → 一级标题（`##` 二级，以此类推）
- `- ` 加空格 → 圆点列表
- `- [ ] ` → 待办方框，点一下就勾上
- `> ` 加空格 → 引用
- `---` 回车 → 分隔线
- 三个反引号包一段 → 代码块

正文里选中文字，`⌘B` 加粗、`⌘I` 斜体，跟其他编辑器一样。

## 四、图片

三种插入方式，图片会直接出现在光标所在的位置：

- **粘贴**：截图后在正文里按 `⌘V`（Windows 是 `Ctrl+V`）
- **拖进来**：从访达里把图片文件拖到正文
- **点按钮**：工具条上的「图片」，从文件里挑

图片插进来之后还能调：

- **挪位置**：按住图片拖，可以拖到任意文字中间
- **改大小**：鼠标放到图片上，拖右下角出现的小圆点；拖到接近满宽就恢复自适应
- **图文混排**：点一下图片，左上角出现「左 / 右 / 整行」。选「左」图片靠左、文字在右边绕排；选「右」图片靠右、文字在左边绕排；选「整行」独占一行。选完光标会自动跳到图片后面，直接打字就行

截图和本地图片会被压缩后**直接存进笔记内容里**，不额外生成图片文件，所以：

- 笔记发给别人、扔进网盘、放进 Git，图片都不会掉
- 代价是 `.md` 文件会变大，一篇塞很多图可能几 MB，属正常

也可以用网络图片，把网址粘进正文，会自动变成可点的链接。

## 五、待办和清单

没有单独的「清单」类型 —— 待办直接写在笔记里，和标题、正文、图片混着放。一篇笔记里既能写想法，也能列今天要做的事。

三种起手方式：

- 工具条点 **☑**，光标所在那行变成待办
- 行首敲 `- [ ] ` 加空格，自动变成待办
- 选中几行再点 **☑**，一次改多行

待办行的用法：

- 点前面的圆圈打勾，再点一次取消；勾掉的会自动加删除线
- 在一项上敲回车，下面直接多出一行待办，接着写就行
- 在空待办上再敲一次回车，退出待办，回到普通正文

编辑器右上角会显示「待办 2/4」这样的完成情况。第二栏的列表里，小圆点是绿色的表示还有没勾完的待办，灰色的就是都收尾了，扫一眼就知道哪些还没弄完。

## 六、记账本

「记账本」这个笔记本是自动建好并置顶的。记账笔记和普通笔记是同一种文件，只是它多一个 `ledger: true` 的标记，打开后是记账界面。

**新建记账笔记**：点第二栏「＋ 新建笔记」右边的「更多 ▾」，选「记账笔记」（也可以按 `⌘⇧N`）。它会自动落到「记账本」里，标题默认是「记账 2026-10」这种格式。

打开就是记账界面：

- 顶部是当月**支出 / 收入 / 结余**，用 ‹ › 翻月份；翻走了会出现「回到本月」
- 中间**记一笔**：先选支出还是收入 → 填金额 → 点分类 → 写备注（可选）→ 点「记一笔」或直接回车
- 右上角是**日期**：点它弹出月历，点哪天就是哪天；下面有「今天 / 明天 / 后天 / 一周后」；想手打也行，直接敲 `2026-10-21`、`10-21` 或 `21`（这只认当月的日子），回车确认
- 分类不够用点「＋ 自定义」，起个名字回车。自己起过的分类会记住，下次直接能选
- 「花在哪了」是当月各分类的占比条
- 下面是按天分的流水，鼠标移到某一行右侧会露出 ×，点掉就删
- **流水默认全部展开**：点日期那一行能把当天收起来，右上角「全部收起 / 全部展开」一次搞定所有天

**数据在哪**：记账笔记的正文就是一张 Markdown 表格。

```
| 日期 | 类型 | 分类 | 金额 | 备注 |
| --- | --- | --- | --- | --- |
| 2026-10-21 | 支出 | 餐饮 | 32.50 | 和同事吃面 |
```

所以用别的编辑器加一行、改个金额，回到简记照样认。界面最下面还有「查看 / 编辑原始 Markdown」，可以当纯文本改。

一篇记账笔记就是一本账。想按月分开记，就多建几篇，各自的月份汇总互不影响。

## 七、重要事项

「重要事项」这个笔记本也是自动建好并置顶的，排在「记账本」下面。它用来放那些**有明确日期、不能忘**的事：交房租、体检、证件到期、项目节点、家人生日……

**新建**：「＋ 新建笔记」右边的「更多 ▾」→ 选「重要事项」。它会自动落到「重要事项」笔记本里，标题默认是「重要事项 2026-10」，固定带一个「重要事项」标记。

打开是事项界面：

- 顶部是**总览**：共几项、待办几项、逾期几项、7 天内几项（有失败事项时会多一格「失败」）
- 中间**记一件**：写事项 → 选级别（紧急 / 重要 / 普通）→ 写备注（可选）→ 点「记一件」或回车。**先不用管日期，记下之后想定再定**
- 下面是清单。**没定日期的先放在最上面的「未设日期」组**，定了日期的按月份分组，比如「2026年10月」。分组默认全部展开，点月份那一行能收起来，右上角也有「全部收起 / 全部展开」
- **排序**：同一组里永远是**待办在最前、失败在中间、已完成在最后**；同状态下按下日期从早到晚
- 每一件日期后面写「还有 4 天」；**过了日子还没做的会标红**写「已过 N 天」
- 做完了点前面的圆圈打勾，完成的会变灰划掉；鼠标移到一行右侧露出 × 删掉
- 上面「全部 / 待办 / 已完成（/ 失败）」可以只看某一类

### 事项的日期：想定再定，随时能改

记下一件事的时候不用管日期，写完就是「未设日期」那一组里的一条，行尾有个虚线的「＋ 日期」：

- **定日期**：点「＋ 日期」弹出月历，点哪天就是哪天；下面还有「今天 / 明天 / 后天 / 一周后」一键选
- **改日期**：点日期本身（比如「10月25日 周六」）就能再开月历重新选
- **清掉日期**：月历右下角有「不设日期」，点了就回到「未设日期」组
- 定完日期，这件事会自动从「未设日期」组挪到那个月的分组里，倒计时也跟着算


### 进度类事项

有些事不是一下做完的，比如「装修」「写论文」「备考」，要分好几步。记一件的时候勾上**「进度类事项」**：

- 默认 **10 步**，旁边的 − / ＋ 或者直接填数字都能改（2–100 步）
- 记下之后，这件事下面会出现一排小方格，**点第几格就走到第几步**；点当前这一格等于退回一格
- 右边会写「3/10」，还差几步也写着；最后一步点完**自动标成已完成**（取消完成会退回一格）
- 不是进度类的事项没有这些小方格，还是原来的一勾到底

### 子事项

进度类事项下面可以再拆子事项：点「＋ 子事项」，写名字回车，能连着加好几个（Esc 结束）。

- 子事项只有**待完成 / 已完成**两种状态，点前面的小方框切换
- 事项那一行会显示「子 1/2」，一眼看出做了几个
- 鼠标移到子事项上，右边露出 × 删掉

### 失败

真的做不成的事（比如没抢到号、项目黄了），鼠标移到那一行右侧点「失败」，填一句原因回车：

- 那件事会标成**已失败**，下面一行写着失败原因
- 总览和筛选里会多出失败数；失败的事项会和待办、已完成分开排
- 想反悔就点「撤销」，回到待办，原因也一起清掉

**数据在哪**：正文同样是一张 Markdown 表格（老版本只有 5 列的表格也能直接打开）。

```
| 日期 | 事项 | 级别 | 状态 | 进度 | 子事项 | 备注 | 失败原因 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-10-25 | 交房租 | 重要 | 待办 | | | 房东账号没变 | |
| 2026-10-30 | 装修 | 紧急 | 待办 | 3/10 | 买水泥 ✓；找师傅 | | |
| 2026-10-18 | 抢名额 | 普通 | 已失败 | | | | 没抢到 |
|  | 年底复盘 | 普通 | 待办 | | | 还没想好哪天 | |
```

日期那一格空着，就是「未设日期」。子事项用 `；` 分隔，名字后面带 `✓` 就是已完成。

## 八、标记

标记就是给笔记贴的标签，自己随便起，比如「重要」「待读」「某项目」。

- **加标记**：打开笔记，标题下面点「＋ 标记」，输入名字（多个用逗号分隔）。弹窗里会列出已经用过的标记，点一下就填进去
- **去标记**：标记右边有个 ×，点掉就行
- **普通笔记默认没有标记**；记账笔记固定带「记账」标记、重要事项笔记固定带「重要事项」标记，这两个删不掉
- **按标记筛选**：左栏最下面的「标记」分组，点一下只看带这个标记的笔记，再点一次取消。它和笔记本范围是叠加的

标记存在文件头的 `tags:` 里，用别的编辑器也能看见：

```
---
title: 周会记录
tags: 重要, 待读
---
```

## 九、搜索

按 `⌘F`，或者直接点第二栏顶部的搜索框。

搜索是**跨所有笔记本**的，标题和正文都会搜。结果里会用橙色小标签标出每篇笔记属于哪个笔记本。

清空搜索框就回到正常的笔记本浏览。

## 十、快捷键

- `⌘N` 新建笔记、`⌘⇧N` 新建记账笔记
- `⌘F` 搜索
- `⌘B` 加粗、`⌘I` 斜体
- `⌘S` 立即保存（平时不用按，停手半秒就自动存了）
- `⌘\` 收起 / 展开笔记本栏

## 十一、文件存在哪

笔记都是普通的 `.md` 文件，放在 `~/Documents/简记/` 下面（Windows 是「我的文档」里的「简记」）。

一个笔记本就是一层子文件夹：

```
简记/
├── 未分类的笔记.md
├── 操作手册.md
└── 工作/
    └── 周报.md
```

这样一来：

- 能用任何编辑器打开，VS Code、Typora、Obsidian 都认
- 备份就是复制整个文件夹
- 可以丢进 Git 做版本管理
- 想手工分组，直接在访达里建文件夹、把文件拖进去，应用下次启动会自动识别

## 十二、几个常见问题

**笔记会被上传吗？**

不会。没有服务器，没有账号，断网照样用。

**改坏了能撤回吗？**

应用内没有撤销。如果笔记放在 Git 仓库里，可以靠 git 恢复。建议定期把整个文件夹备份一份。

**删掉的笔记去哪了？**

直接从磁盘删除，不进废纸篓。删之前想清楚。

**能在多台电脑之间同步吗？**

把 `~/Documents/简记` 放进 iCloud 云盘、网盘同步目录，或者用 Git。应用本身不做同步。

**重名怎么办？**

同一个笔记本里不允许两篇同名笔记，会自动加序号，比如「周报 2.md」。

**以前建的清单还能用吗？**

能。清单和笔记已经合成一种东西，旧的清单笔记打开就是普通笔记，里面的 `- [ ]` 行会自动显示成可勾选的方框，不用做任何迁移。文件里以前那行 `type: list` 会在下次保存时自动清掉。
